# License

NeighborIQ's code is licensed under the **Functional Source License, Version 1.1, ALv2 Future License**
(FSL-1.1-ALv2). The binding text is [`LICENSE.md`](../../LICENSE.md). This page summarises it; if the two
ever disagree, the licence wins.

The idea: you can do almost anything with NeighborIQ except sell it back as a competing product. Every
release then becomes fully open source (Apache 2.0) after two years.

## Common questions

| I want to… | Allowed? |
|---|---|
| Run it to analyse properties for my own rental business | **Yes.** Internal use is explicitly permitted |
| Run it inside my company, for my team | **Yes** |
| Change the code, fork it, keep my changes private | **Yes**, for any permitted purpose |
| Use it in a course, a thesis or research | **Yes.** Non-commercial education and research are permitted |
| Set it up for a client who will use it for their own investing (consulting) | **Yes.** Professional services for a licensee are permitted |
| Publish my fork | **Yes.** Keep the licence and copyright notices with it |
| Offer NeighborIQ, or a service built from it with the same functionality, to others as a paid product or hosted service | **No.** That is a "Competing Use" |
| Do anything at all with a release that is more than two years old | **Yes**, under the Apache License 2.0 |

## What counts as a competing use

A **Competing Use** means making the software available to others in a commercial product or service
that substitutes for NeighborIQ, substitutes for another product the licensor offers using it, or has the same
or substantially similar functionality. Everything else is a **Permitted Purpose**.

## Two-year conversion

Each version carries an irrevocable grant: on the second anniversary of its release it is also licensed
under the [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0). Later versions keep their own
two-year clock.

  and copies obtained under those terms stay MIT-licensed.
- **Data.** The licence covers code only. Open data, OpenStreetMap and any listing feed keep their
  publishers' terms; see [NOTICE](../../NOTICE) and [Data sources](../data-sources.md).
- **Trademarks.** The licence grants no rights to the NeighborIQ name or logo beyond identifying the origin of

- **Contributions** are accepted under the same licence; see [CONTRIBUTING](../../CONTRIBUTING.md).
- **Other licensing.** For uses the FSL does not allow, contact the maintainer through
